---
title: Super Admin Guide
description: Advanced management tasks for system-wide administrators.
---

Super Admins have total control over the Niko Niko Calendar instance. This role is typically reserved for system maintainers.

## 1. Global Overview

Super Admins can see all teams, all users, and all sprints created in the system, regardless of their own team membership.

## 2. User Management

*   **List Users**: Access a complete list of all registered users.
*   **Delete Users**: You have the authority to delete any user account from the system.
*   **Permissions**: Identify and manage Super Admin status for other users.

## 3. Team and Sprint Overrides

*   **Global Visibility**: You can inspect the status and morale of any team.
*   **Management**: You have the power to delete any team or sprint if they violate policies or are created by mistake.

## 4. System Maintenance

*   **Configuration**: Monitor system health and performance.
*   **Troubleshooting**: Investigate issues related to authentication or database consistency.
