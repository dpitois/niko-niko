---
title: Guide Super Admin
description: Tâches de gestion avancées pour les administrateurs globaux du système.
---

Les Super Admins ont un contrôle total sur l'instance de Niko Niko Calendar. Ce rôle est généralement réservé aux mainteneurs du système.

## 1. Vue d'Ensemble Globale

Les Super Admins peuvent voir toutes les équipes, tous les utilisateurs et tous les sprints créés dans le système, indépendamment de leur propre appartenance à une équipe.

## 2. Gestion des Utilisateurs

*   **Liste des Utilisateurs** : Accédez à la liste complète de tous les utilisateurs enregistrés.
*   **Supprimer des Utilisateurs** : Vous avez l'autorité de supprimer n'importe quel compte utilisateur du système.
*   **Permissions** : Identifiez et gérez le statut de Super Admin pour d'autres utilisateurs.

## 3. Administration des Équipes et Sprints

*   **Visibilité Globale** : Vous pouvez inspecter le statut et le moral de n'importe quelle équipe.
*   **Gestion** : Vous avez le pouvoir de supprimer n'importe quelle équipe ou sprint en cas de besoin ou d'erreur de création.

## 4. Maintenance du Système

*   **Configuration** : Surveillez la santé et les performances du système.
*   **Dépannage** : Enquêtez sur les problèmes liés à l'authentification ou à la cohérence de la base de données.
