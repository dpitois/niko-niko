---
title: Guide Admin Équipe
description: Instructions pour les administrateurs d'équipe sur la gestion des équipes, des membres et des sprints.
---

En tant qu'administrateur d'équipe, vous avez des responsabilités supplémentaires pour vous assurer que votre équipe est correctement configurée.

## 1. Créer et Gérer des Équipes

Si vous avez les permissions nécessaires, vous pouvez créer une nouvelle équipe. En tant que créateur, vous devenez automatiquement **l'Admin de l'Équipe**.

*   **Nom de l'Équipe** : Choisissez un nom clair pour votre équipe.
*   **Paramètres** : Vous pouvez mettre à jour le nom de l'équipe ou la supprimer si elle n'est plus nécessaire.

## 2. Gérer les Membres de l'Équipe

Pour suivre le moral, vous devez inviter vos coéquipiers :
1.  Allez dans la section **Gestion de l'Équipe**.
2.  Générez un **Lien d'Invitation**.
3.  Partagez ce lien avec vos collègues. Une fois qu'ils l'auront accepté, ils apparaîtront dans la liste des membres.
4.  Vous pouvez retirer des membres de l'équipe s'ils quittent le projet.

## 3. Gérer les Sprints

Le suivi du moral est organisé autour des **Sprints**.
*   **Créer des Sprints** : Vous devez définir les dates de début et de fin de vos sprints (généralement 2 semaines).
*   **Sprint Actif** : Un seul sprint peut être actif à la fois pour l'enregistrement de l'humeur.
*   **Historique** : Vous pouvez consulter les sprints passés pour analyser les tendances du moral au fil du temps.

## 4. Transférer les Droits d'Administration

Si vous quittez l'équipe ou souhaitez qu'un autre membre la gère, vous pouvez transférer vos droits d'Admin d'Équipe à un autre membre depuis les paramètres de l'équipe.
