---

Bienvenue sur Niko Niko Calendar ! Ce guide vous aidera à faire vos premiers pas avec l'application.

## 1. Commencer

Pour utiliser l'application, vous devez d'abord vous connecter via l'un des fournisseurs OAuth supportés :
*   GitHub
*   Google
*   Discord

Une fois connecté, vous serez redirigé vers votre tableau de bord personnel.

## 2. Votre Tableau de Bord

Le tableau de bord est votre centre de contrôle où vous pouvez :
*   Voir les équipes dont vous êtes membre.
*   Consulter les sprints actifs de vos équipes.
*   Accéder rapidement à la page de saisie d'humeur.

## 3. Enregistrer votre Humeur

La fonctionnalité principale de Niko Niko Calendar est le suivi de votre moral quotidien.
1.  Naviguez vers la page **Saisie d'Humeur**.
2.  Sélectionnez la date pour laquelle vous souhaitez enregistrer votre humeur (doit être comprise dans le sprint actuel et ne pas être dans le futur).
3.  Choisissez l'emoji qui représente le mieux votre ressenti :
    *   🤩 Fantastique
    *   😊 Bien
    *   😐 Neutre
    *   ☹️ Pas terrible
    *   😫 Épuisé
4.  Validez votre saisie. Votre humeur sera partagée avec votre équipe de manière anonymisée (vue collective).

## 4. Visualiser le Moral de l'Équipe

Vous pouvez consulter le moral collectif de votre équipe en naviguant vers la vue calendrier de l'équipe. Cela aide à comprendre le sentiment global de l'équipe et à identifier les tendances.

## 5. Badges et Gamification

En enregistrant régulièrement votre humeur, vous pouvez gagner des badges ! Consultez votre profil pour voir vos accomplissements et encouragez vos coéquipiers à participer.
