# Implementation Plan - Add Prettier to Frontend

## 1. 🔍 Analysis & Context
*   **Objective:** Intégrer Prettier au projet frontend pour standardiser le formatage du code, ajouter un script npm dédié, et documenter cette nouvelle directive dans GEMINI.md.
*   **Affected Files:**
    *   `app/frontend/package.json`
    *   `app/frontend/eslint.config.js`
    *   `GEMINI.md`
    *   `app/frontend/.prettierrc` (New)
    *   `app/frontend/.prettierignore` (New)
*   **Key Dependencies:** `prettier`, `eslint-config-prettier`.
*   **Risks/Unknowns:** Conflits potentiels entre les règles existantes d'ESLint et Prettier si la configuration de compatibilité (`eslint-config-prettier`) n'est pas appliquée correctement dans le contexte du "Flat Config" d'ESLint 9.

## 2. 📋 Checklist
- [ ] Step 1: Installation des dépendances (Prettier & Plugin ESLint).
- [ ] Step 2: Création de la configuration Prettier (.prettierrc & .prettierignore).
- [ ] Step 3: Ajout des scripts npm dans package.json.
- [ ] Step 4: Mise à jour de la configuration ESLint pour désactiver les règles de formatage conflictuelles.
- [ ] Step 5: Mise à jour de la documentation (GEMINI.md).
- [ ] Verification: Exécuter le formatage et vérifier l'absence de conflits ESLint.

## 3. 📝 Step-by-Step Implementation Details

### Step 1: Installation des dépendances
*   **Goal:** Ajouter les outils nécessaires au projet frontend.
*   **Action:**
    *   Exécuter dans `app/frontend`:
        ```bash
        npm install --save-dev prettier eslint-config-prettier
        ```

### Step 2: Création de la configuration Prettier
*   **Goal:** Définir les règles de formatage standard.
*   **Action:**
    *   Créer `app/frontend/.prettierrc` avec le contenu suivant (standard community config):
        ```json
        {
          "semi": true,
          "singleQuote": true,
          "trailingComma": "all",
          "printWidth": 100,
          "tabWidth": 2,
          "endOfLine": "auto"
        }
        ```
    *   Créer `app/frontend/.prettierignore` :
        ```text
        node_modules
        dist
        .stats.html
        package-lock.json
        ```

### Step 3: Ajout des scripts npm
*   **Goal:** Faciliter l'exécution du formatage via `npm run`.
*   **Action:**
    *   Modifier `app/frontend/package.json` section `scripts`:
        *   Ajouter `"format": "prettier --write ."`
        *   Ajouter `"check-format": "prettier --check ."`

### Step 4: Mise à jour de la configuration ESLint
*   **Goal:** Désactiver les règles ESLint qui entrent en conflit avec Prettier.
*   **Action:**
    *   Modifier `app/frontend/eslint.config.js`.
    *   Importer `eslint-config-prettier` (Note: pour ESLint 9 Flat Config, l'usage peut varier légèrement, mais importer le config object et le placer en dernier suffit souvent).
    *   Mise à jour du tableau de configuration `defineConfig` :
        ```javascript
        import prettierConfig from 'eslint-config-prettier'; // Import

        export default defineConfig([
          // ... existant configs ...
          // Ajouter prettierConfig en dernier pour surcharger les autres
          prettierConfig,
        ])
        ```

### Step 5: Mise à jour de la documentation
*   **Goal:** Officialiser la directive de formatage.
*   **Action:**
    *   Modifier `GEMINI.md` à la racine.
    *   Dans la section **Frontend (React)**, après l'étape "Control every changes using ES Lint", ajouter :
        ```markdown
        5.  Format code using Prettier:
            ```bash
            npm run format
            ```
            Ensure code is properly formatted before committing.
        ```

## 4. 🧪 Testing Strategy
*   **Manual Verification:**
    1.  Exécuter `npm run format` dans `app/frontend`. Vérifier que les fichiers sont modifiés (ex: changement de guillemets doubles en simples).
    2.  Exécuter `npm run lint`. Vérifier qu'aucune erreur de style (gérée par Prettier) n'est remontée par ESLint, et que le processus ne crash pas.
    3.  Vérifier que `GEMINI.md` contient bien les nouvelles instructions.

## 5. ✅ Success Criteria
*   La commande `npm run format` fonctionne et formate tous les fichiers `.ts`, `.tsx`, `.css`, etc.
*   La commande `npm run lint` passe avec succès après le formatage.
*   Le fichier `GEMINI.md` est à jour.
