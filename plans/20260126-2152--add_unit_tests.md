### Step 1: Backend - Initialize Unit Test Project
*   **Goal:** Create the xUnit project for services and add necessary NuGet packages.
*   **Action:**
    *   Run `dotnet new xunit -n NikoNiko.Services.UnitTests -o api/NikoNiko.Services.UnitTests`.
    *   Add to solution: `dotnet sln api/nikoniko.slnx add api/NikoNiko.Services.UnitTests/NikoNiko.Services.UnitTests.csproj`.
    *   Add references:
        *   Project: `NikoNiko.Services`, `NikoNiko.Core`.
        *   Packages: `Moq`, `FluentAssertions`.
*   **Verification:** `dotnet build api/NikoNiko.Services.UnitTests` succeeds.
