# Implementation Plan - Allow Team Admin to change team name

## 1. 🔍 Analysis & Context
*   **Objective:** Allow Team Admins and Super Admins to rename a team from the management list, with real-time updates for all connected members via SignalR.
*   **Affected Files:**
    *   `api/NikoNiko.Api/Controllers/TeamsController.cs` (New PUT endpoint)
    *   `api/NikoNiko.Core/DTOs/Team/UpdateTeamDto.cs` (New DTO)
    *   `api/NikoNiko.Services/NotificationService.cs` (Logic for rename notification)
    *   `app/frontend/src/services/teamService.ts` (API call)
    *   `app/frontend/src/components/AdminTeamListItem.tsx` (UI for Edit button)
    *   `app/frontend/src/components/EditTeamDialog.tsx` (New UI component)
    *   `app/frontend/src/context/NotificationContext.tsx` (Handling SignalR event)
*   **Key Dependencies:** 
    *   .NET 10 (Backend)
    *   SignalR (Real-time)
    *   React 19 / MUI v7 (Frontend)
    *   SWR (Data fetching/mutation)
*   **Risks/Unknowns:** 
    *   SignalR target filtering: Ensuring only members of the renamed team receive the specific update trigger.
    *   Validation: Ensuring name constraints are consistent between creation and update.

## 3. 📝 Step-by-Step Implementation Details

### Step 0: Backend - Global DTO Refactoring
*   **Goal:** Standardize DTOs using C# `record` for immutability and conciseness.
*   **Action:**
    *   Identify and convert all files in `api/NikoNiko.Core/DTOs` from `public class X` to `public record X`.
    *   Ensure properties use `{ get; init; }`.
*   **Verification:** Project compiles and existing tests pass.

### Step 1: Backend - Data Transfer Object
*   **Goal:** Define the payload for team updates using modern C# features.
*   **Action:**
    *   Create `api/NikoNiko.Core/DTOs/Team/UpdateTeamDto.cs`:
      ```csharp
      namespace NikoNiko.Core.DTOs.Team;

      /// <summary>
      /// DTO for updating team details.
      /// </summary>
      public record UpdateTeamDto
      {
          /// <summary>
          /// The new name of the team.
          /// </summary>
          public required string Name { get; init; }
      }
      ```
*   **Verification:** Project compiles.

### Step 2: Backend - API Endpoint & Authorization
*   **Goal:** Provide a secure way to update the team name.
*   **Action:**
    *   Modify `api/NikoNiko.Api/Controllers/TeamsController.cs`:
    *   Add `UpdateTeam(Guid teamId, UpdateTeamDto updateTeamDto)` method.
    *   Annotate with `[HttpPut("{teamId}")]` and `[Authorize(Policy = "IsTeamAdmin")]`.
    *   Logic: Find team, update `Name`, `_context.SaveChangesAsync()`.
*   **Verification:** HTTP PUT returns 204 NoContent for admin, 403 for non-admin.

### Step 3: Backend - Real-time Notification
*   **Goal:** Notify members about the name change.
*   **Action:**
    *   In `TeamsController.UpdateTeam`, after `SaveChanges`, call `_notificationService.NotifyTeamRenamed(teamId, newName)`.
    *   Update `INotificationService` and `NotificationService` to include this method.
*   **Verification:** Logs or SignalR debugger shows message sent.

### Step 4: Frontend - API Service
*   **Goal:** Link frontend to the new endpoint.
*   **Action:**
    *   Modify `app/frontend/src/services/teamService.ts`:
    *   Add `updateTeam(teamId: string, name: string): Promise<void>`.
*   **Verification:** Function called in console returns success.

### Step 5: Frontend - UI Components
*   **Goal:** Provide the user interface for renaming.
*   **Action:**
    *   Create `app/frontend/src/components/EditTeamDialog.tsx` using MUI `Dialog`, `TextField`, and `Button`.
    *   Modify `app/frontend/src/components/AdminTeamListItem.tsx`:
        *   Add `EditIcon` button.
        *   Manage state for the dialog visibility.
*   **Verification:** Dialog opens, shows current name, and closes on submit/cancel.

### Step 6: Frontend - Real-time Integration
*   **Goal:** Refresh UI when notification is received.
*   **Action:**
    *   Update notification listener (likely in a context or hook) to listen for `TeamRenamed`.
    *   Action: Call `mutate('/api/teams')` to refresh the team list globally.
*   **Verification:** Renaming in one tab updates the name in another tab without refresh.

## 4. 🧪 Testing Strategy
*   **Unit Tests:** Verify `UpdateTeamDto` validation (if any).
*   **Integration Tests:**
    *   `UpdateTeam_AsAdmin_ReturnsNoContent`
    *   `UpdateTeam_AsMember_ReturnsForbidden`
*   **Manual Verification:**
    1. Login as Team Admin.
    2. Go to Admin Teams.
    3. Click Edit on an entry.
    4. Change name and save.
    5. Verify success snackbar and name update in the list.

## 5. ✅ Success Criteria
*   [ ] Team Admin can change team name from the list.
*   [ ] Non-admin members cannot see the edit button and are blocked by API.
*   [ ] Changes are reflected instantly for other members via SignalR.
*   [ ] UI provides clear feedback (loading states, success snackbars).
